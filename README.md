# Machine Learning Practicals

A collection of 12 practicals covering core machine learning topics, built with Python, scikit-learn, and PyTorch.

| Folder | Topic |
|--------|-------|
| `pract1` | Environment setup and basic data exploration |
| `pract2` | Exploratory data analysis (Ames Housing) |
| `pract3` | Data cleaning and preprocessing |
| `pract4` | Linear regression |
| `pract5` | Classification and evaluation metrics (ROC, precision-recall) |
| `pract6` | Hyperparameter tuning (GridSearchCV) |
| `pract7` | Model comparison (Naive Bayes, KNN) |
| `pract8` | Support Vector Machines |
| `pract9` | Ensemble methods (Decision Trees, Random Forest) |
| `pract10` | Unsupervised learning (PCA, K-Means) |
| `pract11` | Multi-Layer Perceptron (PyTorch) |
| `pract12` | Convolutional Neural Network – Fashion-MNIST (PyTorch) |
